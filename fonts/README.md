# Fonts
Local copies of Google Fonts so renders never depend on the network. `fonts.css` has the @font-face rules (latin subset).
Included: Geist (variable 100-900, incl. italic-free), Geist Mono, Inter, Orbitron (only for the "without skills" comparison poster).
Add more: `python3 fetch_fonts.py "Space Grotesk:wght@400;700"`.
